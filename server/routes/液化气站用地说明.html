一句话结论：政府给你批工业用地，不是搞错了，而是正常的操作顺序。
你是搬迁项目，手里有政府批文，后续规划许可环节自然会解决用途兼容问题。

为什么政府批了工业用地？三个原因

① "兼容"就够了

广东阳西县实例：
三类工业用地(M3)
兼容供燃气用地(U13)

不需要完全变更用地性质，兼容模式程序简单得多。你的控规很可能已经预留了兼容条件。

② 流程还没走到

土地出让 → 用地规划许可 → 工程规划许可，是三个独立环节。

土地证写大类(工业)，规划许可证才写细类(兼容供燃气)。

你现在刚走完第一步。

③ 搬迁批文是钥匙

你手上的政府搬迁批复，就是启动规划兼容/调整的法律依据。

没有批文的新建项目很难调，但搬迁项目——政府有义务帮你把手续跑通。

两种路径对比

✗ 没有搬迁批文（新建）

自己找自然资源局申请控规修改 → 论证报告 → 公示 → 专家评审 → 政府审批 → 3~6个月起步，不一定批

✓ 有搬迁批文（你的情况）

搬迁批复 → 自然资源局启动兼容确认或局部调整 → 绿色通道 → 1~2个月，大概率已预留兼容

你现在要做的：一件事

1
去高新区自然资源局，找到发规划许可证的科室 带上你的搬迁批复文件和土地出让合同，当面问清楚。不用书面申请，先口头沟通。
直接这样问：

"我们是政府批准的液化气站搬迁项目。设计院提醒我们国标把灌瓶站归到U13供燃气用地，而我们的地是工业用地。

想请教一下：咱们控规里是不是已经对这块地预留了供燃气功能兼容？后续出规划许可证的时候流程是怎样的？我们好安排设计进度。"

→ 大概率回复："已经预留兼容了，出证的时候会写清楚。"

三种可能的回复 & 你的应对

对方回复含义你做什么
"控规已兼容，出证时注明" ✓ 最优情况，零额外时间 正常推进设计，准备报建材料
"需要做个小调整，走个程序" 需要控规局部修改，但搬迁项目走绿色通道 配合提交材料，预计1-2个月
"这个我们研究一下" 经办人不确定，需要请示 约下次见面时间，同时找管委会协助推动

一句话记住

你不是去求政府办事，你是去落实政府已经批准的搬迁方案中一个技术细节。
