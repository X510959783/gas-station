## 一、总览

检查机制是一个**联邦制质量保证元系统**。它是"市政府"——不替代任何一个专业机构，但提供它们各自无法单独实现的跨部门协同。

### 架构

```
┌──────────────────────────────────────────────────────────────────────────┐
│                         检查机制 (联邦协调层)                               │
│             协调规则 + 共享接口 + 跨系统触发 + 统一报告                      │
├──────────┬──────────┬──────────┬──────────┬──────────┬──────────┬────────┤
│ 决策审计  │ 架构体系  │ 审计体系  │ 追踪体系  │ 知识管理  │ 违规追踪   │ 进化引擎│
│ (监察局)  │ (警察局)  │ (消防局)  │ (医院)    │ (图书馆)  │ (仪表盘)   │(自学+网学)│
│ 查路:回溯 │ 查言:实时 │ 查物:事后 │ 查行:持续 │ 查知:存取 │ 数据引擎   │无限进化  │
└──────────┴──────────┴──────────┴──────────┴──────────┴──────────┴────────┘
         ↑                                                           ↑
         │              内循环(自学习) + 外循环(联网学)                  │
         └───────────────── 进化引擎驱动 ────────────────────────────┘
```

## 二、七个体系

### 1\. 检查机制 (联邦协调层)

**文件**: `inspection-framework.md`\
**类比**: 市政府\
**职责**: 提供共享语言、跨系统触发规则、统一质量公报、联邦路由

**核心能力** (122轮进化后, 精选):

- 统一JSON消息格式——所有发现用一个Schema报告
- 5条跨系统触发规则 + AGIL响应循环
- 宪法代理(2条不可删除不变量: 老板控制权 + 进化引擎不可禁)
- 模式选择联邦路由(5种模式按信任距离自动选择)
- 死锁检测、心跳检测、断路器、自愈联邦
- 预执行验证门(87%减少有害动作)
- SLO目标体系(99%协调正确率)

### 2\. 决策审计体系

**文件**: `decision-framework.md`\
**类比**: 监察局\
**查**: 路——我的决策对不对\
**核心方法**: DAG路径图回溯、6门控分类(Act/Ask/Refuse/Stop/Confirm/Recover)、三维评分(+1/0/-1)、后悔值驱动优化

**122轮后核心能力**:

- L0: 预判验证(93%准确率, 不执行也能验证)
- L1: DAG有向无环图(2.17x失败检出)
- L2: 捷径检测+三维评分(12%隐藏风险可提前暴露)
- L3: 6门控+Skeptic-Researcher-Judge验证
- 反事实模拟、敏感性分析、后悔值预测、贝叶斯更新

### 3\. 架构体系

**文件**: `arch-framework.md`\
**类比**: 警察局\
**查**: 言——每句话有没有证据\
**核心方法**: 5层闸门(L0验尸→L1禁用语→L2 Toulmin+GRADE→L3复核→L4记忆)、25+禁用语、GRADE证据分级

**122轮后核心能力**:

- 25个中英双禁用语 → 50+多维拦截
- 全轨迹追溯(Claw-Eval: 漏检44%→全覆盖)
- 双循环校准(coSTAR: 验证2周→小时)
- 虚词密度、引用密度、词汇多样性、停顿模式等40+行为信号检测
- 实时意图检测、输出锚定检测、自我反驳生成
- SLO: 80%违规被拦截

### 4\. 审计体系

**文件**: `audit-framework.md`\
**类比**: 消防局\
**查**: 物——系统对不对\
**核心方法**: 9层审计(L1文件→L9双层)、35种取证方法、350遍验证

**122轮后核心能力**:

- L9: Agent级+Span级双层审计(定位精度2.8x-12.5x)
- 15种故障检测 + 2种根因分析(AgentFixer)
- 自愈机制(审计发现→自动修复→验证)
- 幽灵文件/幽灵进程/配置漂移/熵增检测
- 供应链审计(D盘工具本身健康检查)
- SLO: 95%组件被覆盖

### 5\. 追踪体系

**文件**: `track-framework.md`\
**类比**: 医院\
**查**: 行——长期行为模式变化\
**核心方法**: 6个KPI指标、领先/滞后分离、趋势可视化、违规追踪引擎

**122轮后核心能力**:

- K1违规率(基线2.4%)、K2证据密度(基线5.5%)
- 四维退化检测(漂移+异常+疲劳+偏离)
- 情绪分析(老板消息作为补充信号)
- 违规传染链、违规代价量化、预测性告警
- 50+统计分析方法(生存分析、Granger因果、Hamilton回归...)
- SLO: K1&lt;1%、K2&gt;60%、K6&lt;1.5x

### 6\. 知识管理体系

**文件**: `knowledge-framework.md`\
**类比**: 图书馆\
**查**: 知——学到的在哪里\
**核心方法**: TRIAGE→DECAY→CONTEXTUALIZE→CONSOLIDATE→AUDIT五操作循环

**122轮后核心能力**:

- 5种知识类型(DECISION/EVIDENCE/HYPOTHESIS/QUESTION/CONTRADICTION)
- 三层存储(热层会话→温层文件→冷层日志)
- 反馈驱动反向传播(EvoRAG: 推理+7.34%)
- 9-Agent协同富化(KARMA: 83.1%正确率)
- 自导向扩展、遗忘曲线建模、知识免疫
- SLO: 知识可检索率&gt;90%

### 7\. 进化引擎

**文件**: `evolution-engine.md`\
**类比**: 动力源\
**职责**: 驱动所有体系无限进化

**122轮后核心能力**:

- 内循环(自学习): 发现→分析→假设→升级→回测
- 外循环(联网学): 搜索→评估→注入→验证
- MAPE-K自主控制循环
- 赫布学习(有效策略权重+1, 无效-1)
- 5阶段CI/CD安全流水线
- 进化存档、进化回滚、进化基因追溯
- SLO: 有效注入率&gt;70%

## 三、核心协调机制

### 共享消息格式

```json
{
  "source": "audit|arch|track|decision|knowledge|evolution",
  "severity": "Tiger|PaperTiger|Elephant|Info",
  "finding": "具体发现",
  "evidence": "支撑数据",
  "trigger": {"audit":"?","arch":"?","track":"?"}
}
```

### 跨系统触发规则

| 触发 | 动作 |
| --- | --- |
| 审计发现残留 | → 架构新增检查项 |
| 架构发现新编造模式 | → 追踪新增KPI |
| 追踪K1连续2周无改善 | → 审计专项复核 |
| 追踪K6&gt;2x(退化) | → 架构切换快速模式 |
| 审计通过率&lt;95% | → 追踪新增KPI |

### AGIL响应循环

```
Adaptation → 追踪检测异常
Goal → 检查机制判定调整
Integration → 审计确认无副作用
Latency → 新规则持久化
```
