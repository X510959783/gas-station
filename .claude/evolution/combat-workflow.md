# 实战工作流 — L1重心模式

> L1 = 截止前 = 下注决策 = 主输出
> L2 = 赛后 = 学习进化 = 后勤

---

## 核心逻辑

```
L1 (赛前) → 下注决策 → 存快照
     ↓
   比赛结束
     ↓
L2 (赛后) → 完整分析 → 对比L1的偏差
     ↓
   偏差注入框架 → L1下次更准
```

**每一场比赛都是L1的训练样本。** L2数据的唯一用途是帮助L1进化。

---

## 分析输出结构

### L1: 下注决策（主输出）
| 维度 | 数据来源 | 截止前可见？ |
|------|------|:--:|
| D1 赔率区间 | 百家均赔(截止前最后) | ✅ |
| D2 盘口变化 | 亚盘走势(截止前变化) | ✅ |
| D3 赛事类型 | 联赛/轮次 | ✅ |
| D4 庄家共识 | 52家欧赔(截止前终盘) | ✅ |
| D5 凯利指数 | 52家凯利(截止前终盘) | ✅ |
| D6 主任恐惧 | 竞彩(截止前终盘) vs 国际 | ✅ |

### L2: 赛后学习（后勤）
- 截止后的盘口/赔率变化
- 庄家临场操作手法
- L1预测 vs 实际结果的偏差分析
- 框架参数校准

---

## 数据库结构

每场比赛存储：
```
{
  match_id,
  L1: {
    timestamp: 截止时间,
    scores: {D1-D6},
    verdict: 跳过/弱信号/可串关,
    pre_cutoff_changes: 截止前变化数
  },
  actual_result: 比赛结果,
  L2: {
    total_changes: 全部变化数,
    post_cutoff_changes: 截止后变化数,
    behavior_analysis: 庄家手法分析,
    L1_vs_actual: L1预测是否准确
  }
}
```

## 进化循环

每积累10场比赛：
1. D6 gap阈值重新校准
2. D1死亡区/黄金区正路率更新
3. D4极差阈值调整
4. 公司操作手法档案更新
5. L1预测准确率统计
