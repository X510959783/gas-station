## 标签体系

- `[降盘]` 让球减少
- `[升盘]` 让球增加
- `[深盘]` 让球≥1.5
- `[冷门]` 赔率>4倍方赢
- `[诱盘]` 盘口变化与实际相反
- `[真实]` 盘口变化与实际一致
- `[收官]` 赛季末轮
- `[杯赛]` 杯赛决赛/附加赛
- `[强让弱]` 强队让弱队
- `[均势]` 双方实力接近

### 四、贝叶斯融合公式
```
初始概率 = 赔率区间基线正路率
  × 盘口变化修正（降盘+20% / 升盘-30% / 不变=0）
  × 赛事类型修正（收官-30% / 杯赛决赛-20% / 联赛中段=0）
  × 联赛特性修正（德乙-15% / 荷甲-10% / 挪超+5%主场）
  = 最终正路概率
```
