# 六维分析强制检查清单

> L1 = 截止前数据 = 下注决策 = 主输出
> L2 = 赛后全量 = 学习进化 = 后勤

## ⛔ 分析铁律

1. **所有分析必须用 full_analysis.py 执行**，禁止 heredoc 输出分析结果
2. 必须包含完整 8 段，少一段不算完成
3. 脚本报错 → 修脚本，不降级
4. **禁止说"庄家错了"** — 庄家不猜结果，庄家管理风险。赔率反映市场预期和风控逻辑，不是预测
5. **数据一致性优先于固定规则** — 公司数不同、竞彩不在#1不是绝对错误（不同页面不同数量）。真正重要的是：解析结果和页面原始数据必须一模一样。不一致→自动复查→仍不一致→汇报人工对比。透彻分析数据，不以固定数字卡死
6. **知识持续积累** — 每场比赛的分析结果、全网新知识、框架改进点 → 写入对应文件 → 形成独特知识框架 → 大模型随数据积累而进化
7. **任何命令执行前必须自查** — 严谨、全面、一板一眼。自问：数据对吗？逻辑通吗？有遗漏吗？代码和框架一致吗？所有该更新的文件都更新了吗？自查通过才能汇报结果
8. **每日思维进化** — 每天从全网学习思维能力：认知偏误、推理框架、决策科学、AI思维模式、逻辑方法论。集众家之长于一身。不局限于博彩，所有领域的思维方法都吸收

## ⛔ 新比赛门禁

**开始新比赛前必须:**
1. 检查 `issues-tracker.md` — 还有未解决问题吗？
2. 有 → 先修问题，不开始新比赛
3. 无 → 才能继续
4. 本场分析完成后 → 有新问题写入 issues-tracker.md
