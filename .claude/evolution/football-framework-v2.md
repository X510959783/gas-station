# 竞彩六维分析框架 v2 — 从头重建

> 核心假设：竞彩主任和国际庄家坐在同一张桌上——但主任多了29%的防护层。
> 防护层不是无敌的——主任怕的时候——他会用自己的方式"说话"。

---

## 六维全景

| 维度 | 看什么 | 信号 |
|------|--------|------|
| **1. 赔率区间** | 国际赔率1.40-1.49？1.72-1.85？ | 死亡区/黄金区 |
| **2. 盘口变化** | 降盘？升盘？不动？ | 庄家真怕/诱盘/观望 |
| **3. 赛事类型** | 收官轮？杯赛决赛？联赛中段？ | 不确定性等级 |
| **4. 庄家共识** | 多家国际庄家方向一致？分歧？ | 欧赔亚赔分歧=危险 |
| **5. 凯利指数** | K值>1？K值<0.9？ | 庄家亏损预警/舒适区 |
| **6. 🆕 主任恐惧** | 竞彩赔率 vs 国际赔率差距 | 主任主动避险 |

## 第六层：主任恐惧——具体信号

### 信号A：竞彩赔率显著低于国际赔率
```
国际主胜赔率 1.80 → 竞彩主胜赔率 1.65
差距 > 0.10 → 主任在主动压低赔付 → 他怕这个方向
意味着主任知道——如果这个方向打出——他要赔很多
→ 跟主任的方向走
```

### 信号B：竞彩赔率高于国际赔率
```
国际主胜赔率 1.80 → 竞彩主胜赔率 1.95
差距 > 0.10 → 主任在引诱资金到这个方向
他希望你押这边——因为他不怕这个方向
→ 跟主任反向
```

### 信号C：某场比赛不设单关
```
国际赔率可以单买——竞彩不设单关
→ 主任不敢——风险太大
→ 这场比赛的不确定性极高
→ 串关也要避开
```

### 信号D：返奖率异常
```
竞彩正常返奖率 ≈ 71%
某场比赛的计算返奖率突然压到 65% 以下
→ 主任在加保险——他不看好正常方向
→ 冷门概率高
```

## 综合打分——六维评分卡

每场比赛——六维各打 0-1 分：

| 维度 | 1分条件 | 0分条件 |
|------|---------|---------|
| 赔率区间 | 黄金区(1.72-1.85) | 死亡区(1.40-1.49或1.90-2.00) |
| 盘口变化 | 盘口稳定+水位幅度≤10%+早期信号 | 盘口剧烈波动(>10次)或升水>10%或临场突变 |
| 赛事类型 | 联赛中段 | 收官轮(权重0)/杯赛决赛(权重0.5) |
| 庄家共识 | 多家同向+欧亚无矛盾 | 欧赔亚赔分歧或欧赔降+亚盘不升盘 |
| 凯利指数 | K值正常(0.9-1.0) | K值>**1.1**或<0.85 |
| 🆕主任恐惧 | 主任降赔>国际或差距正常 | 主任升赔>国际或差距异常 |

**≤3分 → 跳过**

## 🆕 D6 权重升级 — 基于 2 场验证

**触发条件：**
竞彩 vs 国际赔率差距绝对值 > 0.20（无论是压低还是抬高）

**规则：**
当 D6 触发强信号（|差距| > 0.20）时，总分 +1。

**逻辑：**
主任和国际方向一致 → 弱信号 → 不加权
主任主动背离国际 > 0.20 → 强信号 → 总分 +1

**已验证案例：**

| 比赛 | 竞彩 | 国际 | 差距 | D6 | 加权后 |
|------|:--:|:--:|:--:|:--:|:--:|
| 斯达 vs 瓦勒伦加 | 3.05 | 2.95 | +0.10 | 弱 | 不变 |
| 汉坎 vs 利勒斯特罗姆 | 2.94 | 3.47 | **-0.53** | **强** | **3→4分** |

汉坎这场的 -0.53 差距意味着：主任在拼命压低主胜赔付——他掌握的信息让他极度害怕主胜打出。国际盘反而不看好主胜。结果汉坎 2-0 赢了——主任对了。
