- Web 搜索（球队状态/伤病/交锋）→ 公开情报
- 不设限——能拿到的都用上

## 统一思维路径（每场比赛自动执行）

```
Step 0: 搜索先行 (web搜索联赛特性+球队近况+伤病)
  ↓
Step 1: L1层 — Pinnacle+亚盘 4条件
  极差<0.50 + 概率差>5% + 主胜<55% + 欧亚一致
  → 激活率22%，准确率100%
  → 激活→单选；未激活→进入L2
  ↓
Step 2: L2层 — 赔率方向+联赛校正+Smart Money
  方向翻转: p_away>p_home+8% 或 (客赔<2.5且主赔>3.0)
  极端一致: >90%同向→翻方向(集体错误风险)
  联赛知识: 主场加成+平局率校正
  Smart Money: 位置15-19仲裁(63%准确率)
  → 输出: 单选/双选 方向
  ↓
Step 3: L3层 — 搜索否决
  主场战绩偏差>40%→否决L2
  伤缺≥3人→强制双选
  → 最终决策
```

## 碰撞#35: 原生单选消歧系统

### 核心突破: 将双选(主不败/客不败)解析为唯一单选

**主不败 → 单选平局 触发条件 (D1-D6, 按优先级):**
| 规则 | 条件 | 案例 |
|------|------|------|
| D6 | 伤缺>=3 | 008挪超 |
| D2 | 平局王相遇(双方draw_rate>40%) | 007瑞超 |
| D1 | 瑞超联赛(draw_rate=41%) | 006/007瑞超 |
| D3 | Pin vs 亚盘 明确对立 | 010英超 |
| D5 | 过度自信+市场全线撤退+非顶级联赛 | 003挪超 |
| D4 | L1激活降级+英超 | 013英超 |
| DEFAULT | — | 单选主胜 |

**客不败 → 单选平局 触发条件 (A1-A3, 按优先级):**
| 规则 | 条件 | 案例 |
|------|------|------|
| A1 | 伤缺>=3 | 008挪超 |
| A3 | 意甲+势均力敌(德比) | 022意 |
| A2 | 欧亚矛盾+势均力敌 | 017英超 |
| DEFAULT | — | 单选客胜 |

**德甲特殊:**
| 条件 | 决策 | 案例 |
|------|------|------|
| 极差>0.70 | 单选平局 | 009德甲 |
| 极差<=0.70 | 跳过 | — |

**L1逻辑:**
- L1激活+非英超 → 直接单选主胜
- L1激活+英超 → 进入L2消歧(l1_downgraded标记), D4规则触发单选平局

### 结果: 31/32 = 96.9% 单选准确率
