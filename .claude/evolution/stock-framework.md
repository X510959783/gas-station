# 股市三层过滤 — 博彩模型迁移版

> 博彩和股市——底层同一个数学。市场在什么区间最容易撒谎？

---

## 映射表

| 博彩 | 股市 | 机制 |
|------|------|------|
| 赔率 1.40-1.49 | PE 极高 + "白马股" | 看起来安全——最危险 |
| 赔率 1.72-1.85 | PE 合理 + 被忽视 | 没人抢——反而最稳 |
| 降盘 | 主力资金净流出 | 大钱真的在撤 |
| 升盘+势均力敌 | 盘整期突然拉升 | 诱多——引你接盘 |
| 深盘+收官 | 高位+财报季 | 必暴雷 |
| 欧赔亚赔分歧 | 量价背离 | 矛盾信号——撤退 |

---

## 第一层：估值区间

| PE 区间 | 正路率 | 实战 |
|------|:--:|------|
| PE <10 + 低关注度 | 高 | 🟢 被遗忘的价值——和 1.72-1.85 一样 |
| PE 20-30 + "核心资产" | 中 | ⚠ 市场共识——需第二层 |
| PE >50 + "赛道股" | 低 | 🔴 和 1.40-1.49 一样危险 |
| PE 负 + 概念炒作 | 极低 | 🔴 金螳螂型——击鼓传花 |

## 第二层：资金流向

| 信号 | 博彩对应 | 动作 |
|------|:--:|------|
| 主力净流入 + 股价未涨 | 降盘=庄家悄悄收 | 🟢 跟进 |
| 主力净流出 + 股价未跌 | 升盘=诱多 | 🔴 撤退 |
| 放量拉升 + 龙虎榜游资主导 | 升盘+势均力敌=诱盘 | 🔴 绝对不跟 |
| 缩量下跌 + 机构锁仓 | 深盘维持=真实 | 🟢 持有 |

## 第三层：时间节点

| 节点 | 博彩对应 | 动作 |
|------|:--:|------|
| 财报季前 1 周 | 收官轮 | 任何高位股——自动降权 |
| 政策窗口 | 杯赛决赛 | 不确定性极高——跳过 |
| 节假日前 | 国家队间歇 | 流动性低——反常波动 |
| 正常交易日 | 联赛中段 | 正常分析 |

## 贝叶斯融合公式

```
初始概率 = PE 区间基线正路率
  × 资金流向修正（净流入+20% / 净流出-30% / 量价背离-40%）
  × 时间节点修正（财报季-30% / 政策窗口-20% / 正常=0）
  × 概念/赛道修正（纯概念-50% / 有业绩+10%）
  = 最终正路概率
```

## 第四层：杠杆情绪（体彩凯利指数对应）

| 体彩 | 股市 | 机制 |
|------|------|------|
| 凯利指数 >1 = 庄家亏损 | 融资余额/流通市值 >2.5% = 杠杆过热 | 极度拥挤——踩踏前兆 |
| 凯利指数 <0.9 = 庄家舒适 | 融资占比 9-10% = 正常 | 安全区间 |
| 凯利指数骤降 = 庄家撤了 | 融资连续缩水 5日+ = 杠杆撤退 | **最强预警——体彩降盘** |
| K值方差大 = 多空分歧 | 融资vsETF 方向背离 | 矛盾信号——危险 |

## 第五层：做空力量（体彩返还率+水位对应）

| 体彩 | 股市 | 机制 |
|------|------|------|
| 庄家提高返还率 = 吸引资金 | 券商提高平仓线(115%) = 驱赶杠杆 | 监管主动降温 |
| 水位急升 = 庄家不想要这笔钱 | 融券余额单日激增 = 空头集结 | 看空 |
| 欧赔亚赔分歧 = 诱盘信号 | 华泰买 vs 中金卖 = 量化分歧 | 内部人打架——散户退 |
