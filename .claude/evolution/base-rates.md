# 基线概率库 — "外部视角"操作化

> Tetlock 第 3 条戒律：先用基线概率锚定，再根据具体情况微调。
> 基线来源：Standish CHAOS、IEEE、Google DORA、学术研究。

## 使用方式

```
1. 确定场景 → 查基线概率
2. 分析具体情况（比基线好还是差？）
3. 微调 → 给出最终确信度
4. 记录到 calibration.md 等待验证
```
