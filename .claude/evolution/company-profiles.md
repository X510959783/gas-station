# 博彩公司档案 — 背景、风格、分析用途

> 每家公司背后是不同的资金体量、风险偏好和操盘手法。识别公司秉性 = 读懂盘口语言。

---

## Tier 0 — 独特地位

### 1. 竞彩官方（中国体育彩票）
- **注册地**: 中国
- **返还率**: 71%（法定上限75%）
- **开盘依据**: 香港马会为基础，参考国际公司
- **核心逻辑**: **控制赔付风险优先**，其次才是反映概率
- **手法特征**:
  - 低赔方持续受压（国内玩家偏好"强者恒强"）
  - 1.50-1.60 区间为"低回报陷阱"
  - 平赔 3.00 以下有数字心理学暗示
  - 手法较重、特点鲜明，和马会一样
- **框架用途**: D6 主任恐惧——竞彩 vs 国际赔率差距是独立信号

### 2. Pinnacle 平博（荷兰）
- **注册地**: 荷兰
- **返还率**: 96-98%（业界最低抽水 2-4%）
- **核心特征**: 
  - 赔率最接近事件真实概率——"赔率黄金标准"
  - **不限赢家**，职业玩家不会被限注
  - 纯数据驱动定价，跟随资金流调整
  - 收盘赔率反映所有可用信息
- **信号价值**: ⭐⭐⭐ 最高
  - 平博的盘口变化最可信（不操纵，只跟随信息流）
  - 下跌 = 该方概率真实上升
  - 框架用途: D2 盘口变化首选指标

## Tier 1 — 行业标杆

### 3. 威廉希尔 William Hill（英国）
- **注册地**: 英国
- **行业地位**: 欧赔风向标，80%+ 小公司参考其开盘
- **风格**: 保守稳健，初盘返还率 < 90%，临盘升至 94-95%
- **手法特征**:
  - 主胜低赔下盘赔分布固定，0.05 倍增
  - 英国本土赛事把控力最强
- **框架用途**: D4 庄家共识基准之一

### 4. 立博 Ladbrokes（英国）
- **注册地**: 英国
- **风格**: 极度谨慎，平赔偏执
- **手法特征**:
  - **平局赔率通常开得最低**——平赔异常低 = 防范信号
  - 非英国欧洲赛事谨慎度极高
  - 临盘变化极小，常维持初盘到终盘
- **框架用途**: D4——立博平赔偏低 ≠ 诱盘，是风格使然

### 5. Bet365（英国）
- **注册地**: 英国
- **风格**: 威廉的"影子"但有独立判断
- **手法特征**:
  - 开盘参考威廉，几分钟内调整完毕
  - **当 365 弱方赔率明显高于威廉 → 365 不看好弱方**
  - 返还率 93-95%
- **框架用途**: D4——365 与威廉的背离是重要信号

### 6. 澳门 Macau Slot（中国澳门）
- **注册地**: 中国澳门
- **风格**: 亚洲赛事把控力极强
- **手法特征**:
  - 开盘晚于欧洲公司，但调整更精准
  - 终盘有玄机，赔率微小变化（1.38→1.36）预示关键信息
  - 亚洲赛事最权威
- **框架用途**: D2 盘口变化——澳门终盘信号价值高

### 7. 皇冠 Crown（菲律宾）
- **注册地**: 菲律宾
- **风格**: 灵活调整，资金流向敏感
- **手法特征**:
  - 亚盘异动时常率先调整
  - 竞彩官方常参考皇冠+澳门
  - 与其他公司差异大 = 冷门预警
- **框架用途**: D2——皇冠率先变动 = 资金面信号

## Tier 2 — 重要参考

### 8. 伟德 BetVictor（直布罗陀）
- 英国老牌，风格接近威廉
- 初盘较为保守

### 9. 必发 Betfair（英国）
- **交易所模式**，不是庄家
- 返还率可达 98%（零抽水模式）
- 初期看庄家（深度分析），末期参考必发（即时反应）

### 10. 香港马会 HKJC（中国香港）
- 竞彩的参考来源
- 会员制，赔率本身不高
- 手法重，对风险敏感

## 框架信号速查

| 信号 | 看谁 | 什么意思 |
|------|------|------|
| Pinnacle 降盘 | 平博 | 真实信号——信息流驱动的概率变化 |
| Pinnacle 不变 | 平博 | 无新信息——维持初盘判断 |
| 澳门终盘微调 | 澳门 | 亚洲内部人信息流入 |
| 365 与威廉背离 | Bet365 vs William Hill | 365 不跟 = 365 不看好威廉的方向 |
| 立博平赔异常低 | 立博 | 平局防范——不一定是诱盘 |
| 皇冠率先变动 | 皇冠 | 资金面信号 |
| 竞彩 vs 国际差距 | 竞彩官方 vs 百家均赔 | 主任恐惧指数 |
| 初盘分歧大 | 威廉 vs 立博 vs 365 | 比赛从根源上不确定 |
| 集体压低同一方 | 多家临场同向 | 庄家集体看好 |
| 集体抬高冷门方 | 多家临场同向 | 可能在"集体造冷" |
