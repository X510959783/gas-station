# 知识管理体系 v1.0 — Knowledge Management System
# 建立: 2026-05-28 | 基于 OIDA + MemArchitect + Memory as Metabolism + Yonyou Ontology

## 定位: 查"知"——学到的去哪了?

四个检查体系每天都在产生发现。这些知识存在哪?下周能检索吗?

知识管理体系不做检查,它做**存、理、找、用**。

---

## 核心原理

### 1. 认识论记忆 (来自 OIDA, MIT 2026)
知识不是扁平的文本块。每一条知识有**类型、状态、置信度、来源、时间戳**:

| 知识类型 | 含义 | 处理方式 |
|----------|------|----------|
| **DECISION** | 已做出的决定 | 稳定,直到被新决策取代 |
| **EVIDENCE** | 可验证的支撑数据 | 慢衰减 |
| **HYPOTHESIS** | 未验证的推测 | 不测试则衰减 |
| **QUESTION** | 待解决的开放问题 | **紧急度随时间增长** |
| **CONTRADICTION** | 与已有知识的矛盾 | 非破坏性,加权处理 |

**关键创新**: 未回答的问题也是知识。一个系统知道"自己不知道什么"和知道"自己知道什么"同等重要。

### 2. 记忆代谢 (来自 Memory as Metabolism, 2026)
知识有生命周期——不是越存越多,而是代谢循环:

```
TRIAGE(摄入) → DECAY(衰减) → CONTEXTUALIZE(上下文化) → CONSOLIDATE(巩固) → AUDIT(审计)
```

- **TRIAGE**: 新知识进来,扔掉明显垃圾
- **DECAY**: 未被引用的知识随时间降权
- **CONTEXTUALIZE**: 把知识连接到已有框架
- **CONSOLIDATE**: 批量整理(类似睡眠中的记忆巩固)
- **AUDIT**: 压力测试高权重知识——暂时移除,看查询质量是否下降

### 3. 本体边界 (来自 Yonyou Ontology Harness, 2026)
知识必须在"本体授权边界"内——不是自由检索,而是**约束式推理**。
→ 每条知识有明确的适用域,跨域需显式授权。

## 五个核心操作

### K1: TRIAGE (摄入)
**触发**: 任何体系的检查产生"发现"时
**动作**: 
1. 判断这条知识是新发现还是重复 → 重复则合并,新则创建
2. 分类(DECISION/EVIDENCE/HYPOTHESIS/QUESTION/CONTRADICTION)
3. 如果找不到合适分类 → 标记为QUESTION

### K2: DECAY (衰减)
**触发**: 每周一次
**规则**:
| 条件 | 衰减率 |
|------|--------|
| 从未被引用 | -20%/周 |
| 被引用过 | -5%/周 |
| 是DECISION类型 | 不衰减(直到被superseded) |
| 是QUESTION类型 | **+10%紧急度/周**(不回答越久越紧急) |

### K3: CONTEXTUALIZE (上下文化)
**触发**: 每次摄入后
**动作**: 新知识自动连接到已有知识图谱
- 同领域 → 关联标记
- 矛盾 → 创建CONTRADICTION边,保留双方
- 补充 → 标记"extends"关系

### K4: CONSOLIDATE (巩固)
**触发**: 每次对话结束后
**动作**:
1. 扫描本轮所有发现
2. 合并重复模式
3. 降权被新证据推翻的知识
4. 整理知识图谱交叉引用

### K5: AUDIT (审计)
**触发**: 每10次对话后
**动作**:
1. 选3条最高权重的知识
2. 暂时移除它们
3. 运行测试查询 → 看回答质量是否下降
4. 下降 → 这条知识是"重力知识"(load-bearing),永久保留
5. 不变 → 降权或归档

## 与检查机制的联动

| 知识管理操作 | → 触发什么 |
|-------------|-----------|
| 发现重复决策错误 | → 决策审计体系: 升级为捷径模式 |
| QUESTION类型知识超过30天未解决 | → 追踪体系: K8"知识债务"新KPI |
| CONTRADICTION积累超过5条 | → 架构体系: 复核相关拦截规则 |
| 某个DECISION被推翻 | → 所有体系: 更新引用该决策的规则 |
| AUDIT发现重力知识 | → 生成"不可忘记清单" |

## 执行卡

```
□ 每次对话后: TRIAGE本轮发现 → CONTEXTUALIZE连接到图谱
□ 每次对话后: CONSOLIDATE整理
□ 每周: DECAY衰减旧知识 + AUDIT测试重力知识
□ 每月: 生成知识图谱可视化 + 识别知识债务
```
